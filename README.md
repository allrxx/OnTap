# ON-TAP: Attendance Management System

**ON-TAP** is a digital attendance management solution designed for educational institutions. It replaces manual registers with a centralized, role-based dashboard system that offers real-time insights for administrators and transparency for students.

> **Note:** This project appears to be customized for an academic environment (e.g., Kristu Jayanti College), as indicated by the domain usage.

## 🚀 Key Features

### 🔐 Secure Authentication
* **Graphical Login Interface:** Features a clean, illustrative design emphasizing digital verification (server/client imagery).
* **Role-Based Access:** Secure login for both Administrators and Students using unique IDs (e.g., `22BCAC03`).
* **Account Recovery:** Includes prompts for users who cannot locate their account details.

### 👨‍💼 Admin Dashboard
* **Class Statistics:**
    * **Average Attendance:** View the overall percentage of class attendance (e.g., 73.03%).
    * **Total Students:** Real-time count of enrolled students.
    * **Least Attendance:** Identifies the lowest attendance percentage to help flag students at risk.
* **Leaderboard:** Automatically ranks the top students based on attendance percentage.
* **Management Tools:**
    * Manage Settings and Delete Users.
    * Access specific Student and Admin records.
    * Comprehensive Dashboard view.

### 👨‍🎓 Student Dashboard
* **Personal Tracking:**
    * **Attendance Progress Bar:** Visual representation of the student's current attendance percentage (e.g., 94.53%).
    * **Session Breakdown:** Displays **Total Classes**, **Total Present**, and **Absences**.
* **Academic Information:** Shows current Semester and Batch size.
* **Leave Management:** Dedicated interface for applying for or tracking leave requests.

## 📱 User Interface Highlights

## 🛠️ Usage

1.  **Login:** Enter your unique User ID and Password.
2.  **Dashboard:**
    * **Admins** will see the class overview and leaderboards immediately.
    * **Students** will land on their personal performance card showing their eligibility status.
3.  **Logout:** Securely end the session via the sidebar menu.
